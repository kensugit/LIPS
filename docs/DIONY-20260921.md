## Dellでの適用

専用接続の許可コマンドはstatus/upload/deploy/rollbackで、商品データ取り込みは含まれない（[専用接続の仕様](CODEX-DEPLOY.md)）。Web deployで代用しない。Codexによる自動デプロイは行いません。Dellで手動デプロイしてください。

- 転送済みパッケージ: `artifacts/LIPS-Diony-20260921.tar`。
- SHA256: `86a84bbc26f8e757e82ef2d2a0f0daa625dcfff30f359137e318c259242b831e`。
- Dell保存先: `/home/catalogdeploy/incoming/86a84bbc26f8e757e82ef2d2a0f0daa625dcfff30f359137e318c259242b831e.tar`。
- 実行補助: `artifacts/Apply-Diony-20260921.sh`。

実行補助ファイルをDell利用者のダウンロードフォルダーに保存し、PowerShellで実行する。

```powershell
$script = wsl -d Ubuntu-24.04 --exec wslpath -u "$env:USERPROFILE\Downloads\Apply-Diony-20260921.sh"
wsl -d Ubuntu-24.04 --user root --exec bash "$script"
if ($LASTEXITCODE -ne 0) { throw '取り込みが停止しました。結果を確認してください。' }
```

スクリプトはパッケージ・全収録ファイルのSHA、固定の本番Webイメージ、コンテナ稼働状態、DBポート、Migration互換性、コンテナからの読取権限を検査する。その後、本番DBのpg_dumpと可読性検査を実施してから登録・読み戻し照合する。成功表示は `Diony 516 products imported and verified.`。

転送時の本番総数は5,381。ほかの変更がなければ適用後は5,897となる。適用後に本番URLを指定して `tests/verify-diony-search.cjs` を実行し、検索・出典表示を確認する。「ディオニー」では別仕入先の生産者名にも一致するため、件数確認はDIONYの登録SKUと照合する。

失敗時は追加取り込みを止め、表示されたバックアップを保持する。復元は別DBで確認し、後続データへの影響を管理者が確認してから判断する。本番をローカルdumpや古いdumpで無条件に上書きしない。
