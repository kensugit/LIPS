# 価格帯の自由文検索（v4）

`イタリアの赤ワインで2500円から4000円` を国イタリア・タイプ赤・税抜希望小売2500円以上4000円以下へ変換。上下限を含む。「円から」の片側解析より先に範囲全体を取り出す。「まで」「以内」「以下」、全角数字、カンマ、万円/千円、波線にも対応。逆転範囲や未対応の未満/以上の上端はエラー。詳細欄の価格とは積集合をとる。

前のv3の短縮タイプ（白・赤・ロゼ等）も含む。v3の代わりに `artifacts/LIPS-natural-search-Dell-v4.zip` をDellへ渡し、prepare.sh → 管理者approve → Codex専用deployの順に反映する。本番はまだ初版33459fd7。v4のDellコンテナ検証・本番反映は未実施。

自動79件成功、専用DB/原本依存5件skip。実データ/API/Edge30項目成功。価格帯結果が手動条件の結果全件と一致し、2500円・4000円の境界を確認。既存のシャンパーニュとブルゴーニュ白も回帰確認。Linux向けpublish済み、スキーマ変更なし。ローカル確認URL http://127.0.0.1:55445 。証跡はartifacts/natural-search-range/verification.json。

本番で現在使える表現 `イタリアの赤ワインで2500円以上4000円以下` は29件と実APIで確認済み。本番とローカルの件数を混同しない。アプリ本体の開発元へ解析・テスト・引継ぎを同期済み。統合差分はtools/patches/natural-search-range-and-types.patch。
