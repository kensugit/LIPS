取引先フォルダー、または取引先別フォルダーをまとめた親フォルダーを選びます。例：「取引先別」を選ぶと、その下の「LUC」「Wine to Style」などと、さらに下の資料フォルダーも対象になります。一覧のチェックで対象を選び、「選択したファイルを取り込む」を押すと、このLIPSサーバーへ1ファイルずつ送信します。最初は未処理の有効なファイルが全選択されています。
