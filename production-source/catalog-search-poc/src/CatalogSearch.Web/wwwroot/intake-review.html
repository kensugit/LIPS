原典を確認してください

同じ原典を最新の確認項目で読み直します。確認項目が一致する保存済み回答は保持し、追加の質問を表示します。未保存の入力がある間は更新できません。商品取込は実行しません。

    原典ファイルをダウンロード

    拡大後は画像内を上下左右にスクロールできます。

    原典を見ながら回答する

    左側（狭い画面では上側）の原典画像に対する確認結果です。選んだページ・行の位置は保存時に記録します。

    今回再判定する未保存商品

    価格や数量は上書きしません。条件が一致しなければ保留を続けます。

    各行の確認項目に回答

    原典を見て各行を回答してください。空欄は未回答として保留します。

    同じ資料内の移動です。入力は保持されますが、回答の保存や取込は実行しません。

    次回の同じ帳票に回答を再利用する
    保存した確認項目の回答を、この仕入先・同じ列構成の帳票に再利用します。容量単位と地域略号などの種類、対象列・原略号ごとに分け、同じ確認対象の全行が同じ回答で保存済みの場合だけ設定できます。価格・在庫・容量の実際の値・資料日付は再利用しません。
    回答済みの行から取り込む
    保存済み回答または再利用設定で条件が揃った行だけ取り込みます。条件が揃った行がなければ取り込みません。未回答や商品識別に疑義のある行は保留し、回答後に未保存行だけ追加します。次回への再利用登録は別操作です。
    回答保存と取込再開は別操作です。次へ進んでも取込は実行しません。
