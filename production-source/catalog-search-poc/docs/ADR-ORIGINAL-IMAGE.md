# ADR: 原典画像を保存値再描画と分離する

2026-10-12本人指示。保存値を表に描き直した画像は原典の画像ではないため置換する。

元bytes/hashを真とし、Excel native印刷出力とPDF nativeページレンダリングを派生cacheに保存する。原本の内容・書式を書き換えない。強調を原典とは分離し、原本行/ページと選択方法を回答根拠に保持する。原典範囲未特定時に機械が対象を確定したように表示しない。

隔離WindowsのExcel依存adapterを先行実装。Docker/本番への導入承認・互換レンダラー選定は別工程。CSVや旧xlsを保存値描画で原典画像に見せかけない。
