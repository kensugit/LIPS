# 再利用設定の再読込表示

対象: P14s http://127.0.0.1:56015/intake-review.html?id=f34fb5c5-772c-4245-a4ed-665b89f5235b

画面を開き直すと、保存済み回答とは別にGET /api/import/rulesの現在状態を照合する。最新かつ有効で同じ意味の設定には「再利用保存済み（有効・同じ回答）」を表示し、重複登録ボタンを出さない。

取消済みは取消の表示と明示再登録、異なる意味は相違の表示と明示更新。同一scopeに複数設定がある場合やGET失敗時は未確認として登録しない。GETだけの失敗では原典・保存回答の確認を止めない。

登録操作の直前にもGETし、表示時のID/版/取消/意味と違えば書き込まず最新表示を確認してもらう。同じ有効な回答が既にある場合はPOSTしない。保存時はCASとoperation GET照合を維持し、結果不明なら自動再送・取込再開・次資料移動を停止する。
