# オルヴォーの承認済み1組を内部IDで対応付ける

本人回答「内部IDでこの1組だけ対応付ける」に基づく限定処理。ExcelとPDFの原文を保持し、指定2原典・Excel新着66行・PDF15頁・2024年だけを対象とする。2023年、別資料、別の商品へのルール再利用はしない。原典SKU/JANは補作しない。

## 確認環境と操作

THINKPAD-P14S の `http://127.0.0.1:56018/workspace.html`。専用隔離DBは `lips_aoc_flow_20261013`（55993）。本番環境とは別である。

1. 対象2原典を含む取引先別フォルダーの親フォルダーを選択し、受付を実行する。
2. 取込結果または保留履歴の「固定1ペア」へのリンクを開く。一般判定が保留・未対応でも原典は保存される。別の原典にはこのリンクを出さない。
3. Excel66行とPDF15頁を切り替えて確認する。PDFは2023年の行と区別し、2024年の対象をドラッグすると手動確認範囲が赤枠で表示される。これは自動的な行認定ではない。
4. 提供済みの `LIPS-source-review-answers.json` を選び、原典と回答をプレビューする。新たな回答の提出や同一商品判断の再承認ではなく、既存回答の照合を行う。
5. 原文2名称と2024年限定を確認して、明示登録を実行する。内部IDの商品1件を保存し、各原典の在庫60を加算しない。単位未確定の4価格は根拠として保持し、検索価格には採用しない。

既に登録済みの環境では追加0件となる。保存結果が不明な場合は再送せず「操作記録をGETで照合する」を使う。同じ原典の受付履歴が複数ある場合は対象履歴を選択する。原典全体の保留状態は残り、この1組の処理を全ファイル取込完了と表示しない。

検索画面 `http://127.0.0.1:56018/index.html` では `Cesseras` を検索する。商品詳細で内部IDの種別、両原典の名称、未採用の4価格、原典別数量を確認できる。
