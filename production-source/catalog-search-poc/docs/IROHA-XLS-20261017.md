# いろはわいん旧Excelの一括取込

対象は本番一括取込画面の「いろはわいん」または「IROHA」フォルダー内にある `Stocklist_IROHA_20261001.xls`。本番source `82aa442177b1173b32d1c4e84d3ee5717d1562cd`を起点とする。

- 原本.xlsを変換せず保持し、同梱xlrd 2.0.2で読み取る。原本のマクロ・リンクを実行しない。既存のPython実行パスと、上限・時間制限・ハッシュ照合のあるプロセス境界を使用する。
- 検証済みのIROHA/20261002-v1解析契約を再利用。表題、14列、見出し、原本内の日付2026-10-01を確認する。ファイル名・指定日と原本日付が異なる場合は保存しない。新しい日付・帳票は別途確認する。
- 172商品のSKU、名称、容量、参考上代、税区分、在庫、全元セルと出典行を原本から独立照合。以前承認された同一原本の全172行と一致する。
- 2026-10-02確認済みの仕様に従い、オープン括弧内金額を税抜参考上代に採用する。下代・12本単位の価格は参考上代と分離しRawCellsJsonおよびPriceNoteへ保持する。
- ○・◎から正確な数量を補完しない。グラム表記はmlへ変換せず、原本規格・単位を保持する。
- 同一原本SHA-256は既存の重複判定でスキップする。原本のSHA-256は09A19C4EF423DCAD0F3B15B5FDD2653F6F70802DD3A0F25D860D879B7FA1F747。同日別内容・古い資料を上書きしない既存の保存ガードを維持する。
- DB Migration・DBイメージ・本番商品登録はこのコード変更に含まない。Web展開と、利用者による一括取込実行は別工程。

検証: 回帰531件合格・32件スキップ。実原本を使ったPython解析および.NET一括取込サービスからPythonアダプターへの受け渡しで172件確認、日付不一致と不正ファイルは保存呼出しなし。Linux配布物のPython依存は既存環境を変更せず同梱する。

展開は共通の相互TLS一括転送、最新inspect一致、固定prepareによる読取専用プレビュー、バックアップ、deploy、公開確認を使用する。受信対象の登録とDell管理者による受信開始が必要。未展開の候補を本番対応済みと扱わない。
