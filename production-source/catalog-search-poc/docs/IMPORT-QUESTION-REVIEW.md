## 手順

1. 「確認が必要な資料」から「本人確認_疑義/LUC/日付確認.csv」を選ぶ。本人用合成2ファイルは既に保留で受付済み。再アップロード不要。
2. 専用画面の「原典確認」でCSV行2を選ぶ。対象行が黄色になり、前後の行も画像表示される。小さい画面では画像部分を横スクロールできる。テキスト表示・原本ダウンロードも利用可能。
3. 「確認して回答入力へ」。資料日付2026-10-04、判断根拠「本人確認用の指定日」を入力する。合成試験の既存LUCは10/3まであるため、翌日を使用。実資料の本人指定日とは別の試験条件。
4. 「回答内容を確認する」で確認画面へ。まだ保存しない。「回答を修正する」で戻れる。「この回答を確定する」で回答履歴のみ保存する。
5. 「この原典の処理を再開」で対象1ファイルを取込み、結果画面へ切り替わる。再読込後も結果・回答履歴が残る。完了した資料には再開ボタンが出ない。
6. 「保留継続.csv」は回答入力で「保留を継続する」を選び、根拠を入力・確認・確定する。保留のままで再開しない。

合成フォルダー: LIPS/artifacts/folder-ui-20261011/本人確認_疑義。今回の事前試験商品は3件。手順5後は4件。試験スクリプトは状態変更を含むため無条件に再実行しない。

## 実装範囲と限界

- 一覧に入力フォームを詰め込まず、対象資料ごとに原典確認→回答入力→内容確認→処理結果へ画面切替。各段階で見出しへフォーカスし、現在の段階を表示。
- 原典画像は保存値を読み取った確認用描画。Excelの原本レイアウトのスクリーンショットではない。原本の罫線・字体・配置の再現やPDFページ画像は未対応。
- CSV先頭100物理行、XLSX先頭5シート各50行25列。数式・外部リンクは評価しない。範囲外は原典ダウンロードで参照。疑義の対象位置を特定できないものは位置未特定を表示し、ユーザーが行を選択する。
- 選択したシート・行を回答根拠に保存。原本bytes/hash、質問、回答版、Rule/Human、回答・処理履歴を維持。
- 型付き再開は資料日付。価格・数量競合等は保留継続。自由文だけで業務値を変更しない。
- Running/Unknownは再開不可。通信失敗時は状態を再取得し、自動再送しない。localhost専用境界を維持。
- LLM候補生成・外部API・本番操作なし。ENEOS競合等の専用判断処理への接続は残項目。
