# ADR 0007: キーワード検索と候補確認の更新検知
Status: Accepted, 2026-09-17

検索は空白（全角空白を含む）で区切った語をAND条件とする。各語は項目間OR、英字は大小を区別しない。商品検索は既存のsimple FTSと部分一致を併用する。SQL LIKEの%・_・バックスラッシュはリテラルとしてエスケープし、これらを含む語ではFTSを使わない。日本語形態素解析・意味検索・AIランキングの実装とは区別する。SQLによる容量・年・税抜価格・在庫フィルター、最大2000件の取得制限を維持する。

候補は正規化名称・正の容量・空でない年表記の一致を必須とし、両側に同じ言語の生産者情報がある場合はそれも一致を必須とする。別名・翻訳を推測しない。生産者欠損は画面に表示し、JAN・箱有無等の原本確認を促す。自動Linkはしない。

確認画面の対象RecordHash/SourceDocumentIdと候補SourceDocumentIdを保存要求に添え、変更を検知したら409で再読み込みを促す。取込・内部同期・確認の書込みは同じtransaction advisory lockを先に取得する。PoCでは一括直列化による待ち時間を許容し、共有運用時に負荷を評価する。DBスキーマ変更はない。
