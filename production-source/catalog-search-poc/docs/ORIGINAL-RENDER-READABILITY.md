# 横長Excel原典の高精細表示

横長Excelを1ページ幅に印刷したPDFの低解像度画像では、ブラウザー400%拡大後も容量見出し・数値が潰れていた。Windows Excel経路は、原典をread-onlyで印刷したPDFから対象領域を直接clipして高精細に描画する。保存値からの表再構築や原本更新はしない。

## 描画と上限

Excelの対象範囲幅に対して2px/pt以上、対象行32px以上を目標とする。最終幅16000px・高さ8000px・3200万画素を割当前に検査し、超過は原典ダウンロードを案内して停止する。PDFiumへ渡すclipにより、全ページの巨大bitmapは確保しない。

強調用PDFは位置検出だけに使用し、表示画像は元PDFから生成する。強調ONは対象行の外側へ2px赤枠だけ追加し、対象行内部の画素はOFFと完全一致する。通常PDFの描画とLinux Excel経路は変更していない。

Windows XLSXのみキャッシュ世代を `v2-native-density` とする。既存v1キャッシュを削除する必要はない。変更されたrendererとWebを同時に配布する。

## 操作

1. 原典・回答画面で対象行の画像を表示する。
2. 「原寸（100%）」を押し、画像内を横スクロールして確認列へ移動する。
3. 必要に応じ拡大する。手動倍率と未保存入力は質問行の移動後も保持する。
4. 横幅合わせは全体確認用。文字が小さい場合は原寸で確認する。
