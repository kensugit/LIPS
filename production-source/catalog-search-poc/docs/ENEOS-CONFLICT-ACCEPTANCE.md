- 価格一致は金額だけでは不十分。希望小売と納入価格を混同せず、税区分・単品/ケース等の比較対象を明示する。null同士を自動的に価格一致にしない。特に高級リストは上代オープンで納入価格を持つため、その価格契約を別途明確にする。
- 原本別数量を返す読取API・詳細画面が未実装なら、保存側だけ変更して本人確認可能とはしない。
- 単一数量nullを在庫なしへ変換しない。在庫状態も原文・出典を保持し、相反する状態を後勝ちで解消しない。
- 同一仕入先ロックとDB transactionの内側で全既存同日Evidenceを照合する。ファイル内の重複も保存前に検証する。
- 本番DB変更なし。新しい隔離fixtureで検証し、既存6435商品の本人確認DBを試験リセットしない。
