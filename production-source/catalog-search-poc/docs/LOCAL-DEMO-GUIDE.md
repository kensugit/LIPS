# 商品カタログ：動作確認手順

最新の追加機能は [取込・横断検索の手順](WORKFLOWS-GUIDE.md) を参照。以下の検証件数は検索UI追加時の記録です。

2026-09-17。Wine to Styleの1,061商品は確認用PostgreSQLへ保存済みです。今回の確認ではExcelの再取込や設定入力は不要です。

## 1. 起動する

この手順書と同じoutputsフォルダーにある **Start-Catalog-Demo.cmd** をエクスプローラーでダブルクリックしてください。
PostgreSQLと検索画面が起動し、ブラウザが開きます。開かない場合は http://127.0.0.1:55440 を開いてください。
初期表示は「登録商品 1,061件」「検索結果 1,061件」です。1ページ50件で、下部の「次へ」で進めます。

このPC専用の確認モードです。ログインは不要です。他のPCからのアクセスは受け付けません。

## 2. 確認用の検索を行う

**「確認用の条件を入れる」** を押してください。次の条件が入り、そのまま検索されます。

- 国：フランス
- 産地：ブルゴーニュ
- タイプ：赤
- 希望小売価格の上限：税抜10,000円
- 在庫あり・少量のみ：チェックあり

**検索結果が40件**になります。日英商品名、生産者、年、容量、希望小売価格、在庫が表示されます。
「在庫あり」で本数がない商品は、原本のOK表記です。数量が明記されている商品には本数も出ます。

## 3. 取込元を確認する

任意の商品右側にある **「ワインリスト!行番号」** を押してください。
元ファイル名・在庫表の日付・シートと行番号・価格と在庫の原表記・JAN・品種が表示されます。
**「元のセル内容を見る」** でセル番地と元表記も確認できます。
「閉じる」またはEscで結果へ戻ります。検索条件は保持されます。

## 4. 条件を変える

「条件をクリア」で1,061件へ戻ります。
商品名欄に `__NO_MATCH__` を入れて検索すると、0件の案内を確認できます。
商品名・生産者・産地欄はキーワード検索です。自然文の意味検索やAI検索はまだ実装していません。
価格上限ありの場合、オープン価格など金額のない商品と税込の商品は対象外になります。
在庫空欄は「不明」と表示され、在庫なしには変換しません。

## 5. 終了する

ブラウザを閉じ、同じフォルダーの **Stop-Catalog-Demo.cmd** をダブルクリックしてください。
確認用WebとPostgreSQLが停止します。商品データは残るため、次回も開始ファイルだけで確認できます。

## 困った場合

- 起動済みと出る：終了ファイルを実行してから開始してください。
- 接続できない：開始ファイルを実行し、ブラウザを再読み込みしてください。
- ポート使用中：55439/55440を使う別プロセスを勝手に終了せず、エラー内容を確認してください。
- 作業フォルダーの移動後に開けない：開始ファイルはこのPCの専用worktreeと検証用PostgreSQLを参照しています。フォルダーを移動・削除した場合はパスの修正が必要です。

## 追加検索条件（2026-09-17）

- 容量：登録済みの容量をml単位で選択。完全一致、未指定なら全容量。
- ヴィンテージ：年号・NV・MVを選択。原表記の完全一致、未指定ならすべて。
- 希望小売価格：税抜の下限～上限。両端を含む。片方だけの指定も可能。
- 下限が上限を超える場合は案内を表示。価格指定時は金額なし/税込を除外。
- 「条件をクリア」で追加条件も解除。「確認用の条件を入れる」は追加条件を解除して従来の40件条件へ戻す。

確認例：国・産地・タイプはすべて、在庫限定はOFF、容量750ml、ヴィンテージ2023、下限5000円、上限10000円で **63件**。
開始・終了ファイルは従来と同じ。開始後にブラウザを再読み込みして使用する。

追加のブラウザ確認18項目、既存ブラウザ回帰16項目、実PostgreSQLを使う自動テスト17件成功。自動テストには全Excelから独立に計算した8条件のSKU集合照合を追加。ビルド警告0・エラー0。
影響範囲：検索条件フォーム、候補API、検索API、CLI検索、SQL検索サービス。DBスキーマ・既存iWSET画面は変更なし。
検証スクリプト：verification/verify-filters.cjs。証跡：artifacts/filters-result.json、artifacts/tests/filters.trx。
本番デプロイなし。検証用Web/DBは確認終了後停止。

## 列分離と見出しソート（2026-09-17）

検索結果を商品・生産者・国・産地・年・容量・希望小売価格・在庫の8列＋取込元に分離。
8列のタイトルをクリックすると昇順、同じ列を再クリックすると降順。選択中は▲/▼とaria-sortで明示。
取得した検索結果（最大2,000件）全体を並べ替えた後に50件ずつ表示する。切替時は先頭ページへ戻り、再検索でも選択順を保持。
容量と価格は数値順。文字列は日本語・自然数順、年は年号/NV/MVの原表記で比較。空欄/金額なしは両方向とも末尾。
在庫の昇順は在庫なし→少量→在庫あり→入荷待ち、同じ状態は本数順。本数未記載はその状態の末尾、不明状態は全体の末尾。価格は表示された希望小売価格の数値を比較し、税込/税抜換算はしない（列内に税区分を表示）。
取込元ボタンは従来どおり。スマートフォンでは表内を横スクロールして各列を確認できる。

build成功（警告0・エラー0）、並び替え自動確認48項目、既存UI16＋検索条件18項目成功。実1061件で確認し、DB/API/本番は変更なし。
確認スクリプト: verification/verify-sort.cjs。検証後Web/DBとブラウザは停止。
