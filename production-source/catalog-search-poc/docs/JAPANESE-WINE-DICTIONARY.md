# 日本語の品種・産地・味覚辞書

品種・産地・味覚のデータは `src/CatalogSearch.Application/Dictionaries/wine-search.ja.json` で管理する。辞書ファイルは配布時にアプリへ組み込み、読込み時の形式・別名検証とSHA-256を検索スナップショットへ反映する。日常の追加や修正はデータファイルを更新し、レビューと通常の配布で反映する。

品種と産地の既知の別名をローカルで照合する。辞書が解釈できる形式ではLLMを呼ばず、採用した日本語条件を画面に表示する。辞書では扱わない自由文は既存のAI解釈を利用し、辞書で検出した品種だけを候補として渡す。味覚語を含む条件が確定できない場合は確認を求める。画面指定の取引先、国、産地、色、価格、在庫を優先する。

- 産地はロワール、シノン、ボルドー、ブルゴーニュ、シャンパーニュ、トスカーナ、プーリア、エルギン、ステレンボッシュ、スワートランド、西ケープ州、モーゼル、ラインガウ、ファルツ、ラインヘッセンを初期対象にする。登録名と国が一致した行に限定する。ロワールには [InterLoire の公表資料](https://www.vinsdeloire.fr/fr/vins-loire?page=0) に沿う確認済みの下位産地を含める。エルギンは [Wines of South Africa の産地情報](https://www.wosa.co.za/The-Industry/Winegrowing-Areas/Winelands-of-South-Africa) を参照した。
- カタログの国と産地の対応を読取りスナップショットから参照する。辞書の初期15産地以外も、登録産地名と国の組が一意に照合できる場合に検索できる。上位産地への自動分類は出典のある対応表を追加する。
- 品種は Kym Anderson、Signe Nelgen、Germán Puga の [Adelaide University 品種名・別名データ v1](https://doi.org/10.25909/32870405.v1)（[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)）を基に、[Wikidata](https://www.wikidata.org/wiki/Wikidata:Licensing)（CC0）と確認済み表記から日本語を追加した。ベース辞書は2,006品種。検索辞書は、出典の照合と重複検証ができた296品種を収録する。要レビューの別名はベースへ残す。
- 「主体」は、商品別の原本または照合済み公式資料に配合50%超または主体の明記がある場合に限る。フィネス原本の品種欄が空欄の場合だけ、同じ商品名で始まる説明欄の先頭に独立した配合記載があれば使う。対象例は [ドメーヌ・ド・ラ・ノブレ](https://finesse-wine.co.jp/producteur/valeedeloire/376/) のシノン赤2銘柄。
- 味覚検索は甘口・極甘口・やや甘口・辛口・やや辛口と、柑橘系・果実味・樽香・スパイシーを対象にする。原本の欄または説明の記載を使う。否定・矛盾・記載なしの場合は該当扱いにしない。
- 既存の公式商品補完を利用する条件では、同一商品・ヴィンテージ・原本のハッシュに照合した補完記録を読む。配合率のない公式品種欄は含有の根拠に使う。今回のアプリ配布候補に本番キャッシュの作成・権限変更は含めない。

## 受入例

- ロワールのカベルネフラン主体の赤ワイン
- 南アフリカのエルギン
- ドイツの甘口白ワイン
- 柑橘系の風味の白ワイン

本番では切替後に、採用条件と結果を確認する。商品価格、在庫、取引先原本とDBスキーマは保持する。

## タイプ・在庫・年号の表記

- `src/CatalogSearch.Application/Dictionaries/catalog-search-elements.ja.json` に、ワインのタイプ、在庫あり、ノンヴィンテージの表記を収録する。ファイルの形式と別名の重複を検証し、SHA-256を検索スナップショットに含める。
- 「発泡性ワイン」「sparkling wine」を発泡タイプに結び付け、取込原本で確認した `白/泡`、`泡ロゼ`、`発泡白` 等のタイプ値を照合する。微発泡や別種の酒類は検索用の発泡タイプに自動統合しない。「シャンパン」は既存の産地条件を保持する。
- 「在庫が有る」「在庫あり」を既存の在庫あり・少量条件として扱う。不明や欠品は対象外。「ノンヴィンテージ」「ＮＶ」は明示されたNVとして照合する。空欄・不明・不完全な年号は推定しない。
- 自由文全体を規則で処理できた場合はLLMを呼ばない。価格・容量は既存の数値・単位変換、取引先は登録名とコード、通常の商品名・SKUは既存の文字検索を用いる。辞書の対象外や複雑な指定は既存のAI解釈と確認の対象とする。
- 受入例は「在庫が有るノンヴィンテージの発泡性ワイン」「在庫ありのホワイトワイン」「辛口のスパークリングワイン」。画面のタイプや年号指定がある場合は画面を優先する。
